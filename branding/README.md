# Focal branding

`focal-icon.svg` is the canonical Focal app mark.

The overlapping translucent panes retain the restrained blue palette while adding depth and a clearer visual identity around organised layers of study material.

Desktop dev/build uses the checked-in icons in `src-tauri/icons/`. When the mark changes, Tauri's icon generator accepts this SVG directly; retain the desktop icons from its output.
