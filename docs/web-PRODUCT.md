# Product context

Focal helps VCE students plan study, record practice exams, review mistakes, and understand their progress. The shared web and desktop interface supports individual study, with optional account sync, friends, reminders, and AI tools.

Keep the next action easy to find, distinguish estimates from official reference data, and make recording work quick enough to use after a study session or paper. Preserve local data and user-controlled exports. Aim for accessible keyboard and touch interactions, visible focus, and information that does not depend on color alone.

See [interface design](web-DESIGN.md) and the repository's [product context](../PRODUCT.md).
