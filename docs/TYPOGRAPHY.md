# Typography

The shared UI defaults to Instrument Sans for body text and Newsreader for headings. Fonts and theme variables are defined in `src/index.css`; users can choose other body and heading fonts in appearance settings (`src/lib/appearance.ts`).

Use the existing Tailwind text sizes and nearby component patterns for hierarchy. Keep labels and body copy readable, use tabular numerals for aligned measurements, and check both light and dark themes. Avoid relying on tiny text for essential instructions or status.
