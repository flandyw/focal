# Typography

The shared UI defaults to Instrument Sans for both body text and headings, keeping headings compact and semibold (`.focal-page-title`, `.focal-section-title`, `.focal-stat-value` in `src/index.css`). Newsreader is also available as an optional heading font. Fonts and theme variables live in `src/index.css`, and students can pick other body and heading fonts in Appearance settings (`src/lib/appearance.ts`).

Stick to the existing Tailwind text sizes and nearby component patterns so pages feel consistent. Keep labels and body copy comfortable to read, use tabular numerals wherever numbers line up, and check both light and dark themes. Don't hide important instructions or status inside tiny text.
